## 2. 用户场景

1. 使用者从 Hub 进入，日期默认截至今天近一年；选择“注射用水”、取样点和检项，查看电导率或 TOC 趋势并展开原值；可一键切换近一个季度、半年或一年，也可自定义日期。
2. 使用者选择微生物检项，查看 `<1` 与精确数值的分布；汇总显示两种数量，不把所有值混入普通均值。
3. 使用者查看季度汇总，切换“已复核”和“测完未复核”；页面和导出使用同一状态口径。
4. 查看＋导出用户按当前趋势筛选下载 PNG、Excel 或图表组合包，图表与原始数据逐行可核对；仅查看用户不显示导出入口，直接调用任一导出类型也返回 403。
5. 取样点未映射、数据中有方法缺口或未配置限度时，页面显示缺口；用户仍可核对已有来源明细。

## 3. 非功能要求

- 业务 API 默认需要身份与对应角色，真实数据只读；后端拒绝客户端传入任意 SQL、表名和排序表达式。
- 前后端通过 Hub 同源路径工作，链接、静态资源、API 与刷新深链均正确。
- 原值、单位、状态、方法版本与日期来源随结果保留；统计规则版本能够识别。
- 页面/导出避免暴露密码、令牌、数据库连接串；日志保留必要事件而不记录完整业务结果。
- 性能基线在 Mac 实测后写入 docs/09；不得将未实测目标宣称为通过。

需求变更同时更新页面/API、测试追踪和决策台账。

## 4. 统一筛选的适用范围

总览、趋势、结果、汇总和导出基于同一已入选结果集合与 FilterSpec。数据质量页额外提供候选覆盖核对与“日期/取样点未归属”分区，这些记录可能尚未进入宽表或无法落入所选时间/点位；各分区说明查询范围、分母和排除原因，不能冒充主看板同一集合的数量。详细定义见 docs/03 与 docs/07。


### 级联规则（2026-10-09 已确认）

按界面顺序向下联动：水类型 → 水点号 → 内部点位 → 检项 → 方法 → 版本 → 阶段 → 参数 → 单位。每项候选受日期、状态及前面的已选条件限制，忽略自身和后面的选择；未选上游不限制下游。更改或清除上游会清空后续选择；日期/状态改变保留水类型并清空点位及后续选择。点位候选依据现有 staging 关联，不按编号前缀猜测。完整范围与验证见 [变更记录](changes/20261009-cascading-filters.md)。
