# 旧看板交互恢复清单

2026-09-16。依据负责人“按旧看板继续”的反馈，以本地 `quality_analysis_dashboard` 的实际页面代码为参照。仅在Mac开发，不改旧看板、数据库或Linux。

## 本轮放行页设计

采用旧版的左侧导航/筛选、右侧指标组合、按检测项依次展示图表和统计。趋势图与分组均值图按约7:3并排；窄屏上下排列。筛选器不再占用右侧顶部的一整排，图表优先于总表。

颜色沿用旧版分析图语义：标题蓝 `#1A5276`、组别蓝 `#1f77b4`、文字 `#1B2631`、浅灰侧栏 `#f5f7fa`、白色画布 `#ffffff`；规格红与统计参考线独立。中文字体用PingFang SC/微软雅黑，正文14px、模块标题24px、属性标题18px。页面不增加装饰性大数字、渐变或多余卡片。

```text
标题与登录状态
导航 / 数据筛选  | 放行趋势分析
项目、样品       | 常用指标组合
产线、组别、批号 | 已应用条件 / 数据范围
类别、批号年份   | 检测项中文名与原始标识
指标、统计方式   | 趋势图（70%） | 组别均值与SD（30%）
分析 / 重置      | 当前样本统计 / 可展开完整总表
```

设计复核：从通用后台的“顶部筛选+总表+逐张图”恢复为旧版以分析图为主的工作区。保留现有React/AntD，不为改变技术栈重排用户习惯。

## 边界与待办

- 放行的产线、组别、批号、检验类别、批号年份筛选须在服务端生效，空选择代表全部；不截断源批号、不合并重复观察。年份沿用已有旧版解析函数，明确命名“批号年份（推算）”，不能当作检测日期；无法识别者保留且可选择。
- 常用指标/中文别名来自旧版配置，只用于选择和显示；未匹配指标明确提示，不进行猜测映射，也不自动回退成其他指标。
- 当前仍逐项目分析，不合并不同项目套用同一规格。后续已加入RD及旧QC共享staging来源切换，范围见 [来源记录](QAP-DATA-SOURCES-001.md)；完整生产/GMP快照链未验收。
- 本轮恢复既有服务返回的组别均值/SD、参考线显示和统计表布局，不改数值换算、规格或能力指数算法。旧版历史年份参考集与当前样本的统计不同，历史回顾计算待单独核对，不能用同样外观冒充相同结果。
- 稳定性/相似性页面另批接通；正式导入与业务审计继续遵循数据库实施方案。

## 本轮已完成与验证

- 已实现上述放行布局、准确匹配的七类常用指标组合、源单位显示、均值/SD/旧规格线开关、分组均值和样本SD误差线、单项及完整统计汇总。规格线默认隐藏；多单位给出提示，不新增换算。未匹配组合项列明，不能视为已完成指标主数据对齐。
- 后端新增只读筛选选项接口；组别、批号、检验类别及推算年份实际参与筛选。缺失批号/组别、重复观察仍保留；缺失组别计入分组统计。前端显式使用服务端批号顺序，避免分组绘图把交错批号重新排列。
- 修改筛选即清除旧结果；更换项目清除上个项目的条件；请求取消和序号检查共同避免迟到结果覆盖。分析按钮只在所选项目的筛选项可用后开放。
- 截图复核发现窄屏缩放时分组图容器高度可能塌缩，已为两张图明确保留显示高度，并隔离Plotly会修改的轴配置；浏览器回归检查全部图表SVG高度，避免仅凭“不溢出”误判。
- 后端全量 **154 passed，10条既有统计警告**；前端会话6项、TypeScript/Vite构建通过。放行浏览器回归覆盖准确匹配、筛选请求、交错组别批号顺序、迟到响应、跨项目条件清理、空结果、手机无横向溢出与图表堆叠。登录/导入预览浏览器回归通过。浏览器均使用合成身份/响应，不能代替真实MDM或统计业务验收。
- Mac真实只读接口另做抽查：项目→筛选选项→指定源批号分析，核对返回批号原值及观察数/分组数一致；未写数据。截图检查桌面1500px、手机390px，未访问Linux。
