# 01 · 项目说明与准入

> 版本：0.7｜日期：2026-10-09｜状态：两页范围已明确；三卡片及两页方案已明确并授权实施；执行状态见STATUS。

## 1. 定位与已确认要求

`cmc-water-system-dashboard`（制药用水看板）面向纯化水、注射用水、纯蒸汽的 QC 检验结果，用户最新要求仅保留水系统总览与按点位/方法的趋势，趋势包含原文表、追溯与导出；删除独立结果明细、期间汇总、数据质量功能。总览仅WFI/PW/PS三卡片，具体口径见[两页整理设计](changes/20261009-two-page-dashboard.md)；位置/系统归属待用户对照表后另做。

已确认 Mac 开发验证→GitHub→Linux 发布，Hub 唯一入口，MDM 两档业务角色；日期默认截至今天近12日历月，快捷近3/6/12个月；导出图和对应已入选结果原文表。基础代码、独立仓库和服务发布已有证据，但真实两档身份、最新级联浏览器操作及文件落盘验收仍未完成，详见 [状态登记](STATUS.md)。

使用人群为 QC、QA 和水系统相关人员，具体名单与授权由负责人确定。当前用途为趋势核对；GMP 来源不等于看板已验证或可用于放行、APR/PQR等正式受控用途（OP-08）。

## 2. 范围与阶段

| 阶段 | 工作 | 完成条件 |
|---|---|---|
| A 文档与预检 | 数据/规则/权限/页面及准入核对 | 依赖有证据，未关闭事项有编号 |
| B Mac实现和验收 | 基础分析、导出、Hub/MDM接入 | 代码、数据、身份与浏览器分别验收；当前部分完成 |
| C Linux服务发布和业务验收 | 固定代码版本、环境配置、数据与角色 | 服务发布已有记录；业务启用仍需真实身份/浏览器及用途所需快照条件 |
| D 按用途扩展 | 警戒/行动/规格判断与正式受控报告 | 先确认业务口径、验证、审计与快照要求 |

阶段C的服务安装不等于全部业务验收完成。OP-06所涉受控快照在常规GMP分析用途启用前处理，不能因已有服务就视为豁免。

调整后范围为 FR-01–FR-07、收缩后的FR-09、FR-11、FR-13及未配置限度提示；FR-08/10由本次用户指令撤销，代码已删除；FR-12实际限度判断为依赖业务规则的条件功能。SCADA在线信号、设备控制、取样任务、结果录入/修改、电子审批和偏差处理不在当前范围。未实现目标保留在 [功能需求](02-functional-requirements.md) 和 [差距台账](10-decisions-open-items.md)，此次三项功能撤销按用户明确指令登记；其他未完成目标不随文档整理自动取消。
