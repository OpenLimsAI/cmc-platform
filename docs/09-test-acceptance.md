## 3. 抽样设计

按三类水样、主要检项、方法版本、年度/季度、取样点和状态分层取样。至少覆盖电导率方法1双参数、纯化水旧方法选择、TOC、微生物删失、定性结论、空取样点、日期回退与已知方法缺口。实际样品和数量在验证记录中填写，敏感细节控制在适当位置。

对账使用独立查询或人工核算，不只是调用同一服务生成“期望值”。历史 84,620 水系统结果行可作为日期化参照，不能用硬编码数量作为未来更新后的通过条件。检项计数不能使用未经验证的宽表字段推断实例。

## 4. 性能与测试范围

针对真实风险验证解析、计数、比较组、限度、授权和查询一致性。前端构建/类型检查、相关后端测试、nginx 配置验证按实现工具链执行。性能记录典型总览、单点年度趋势、分页与导出的数据量/耗时/查询计划，再确定 OP-11 的上限。

没有限度配置时仍可验收基础展示，但限度判断不能登记通过。没有 Linux 数据时不能登记业务上线通过。正式受控用途的确认/验证范围按 OP-08 扩展，不由开发验收自动代替。

## 6. 文档复核新增的验证点

- AT-01/02：role 集合空/非法、导出集合超出查看集合均启动失败；SYS_ADMIN 不能绕过过期/临时密码检查；模拟旧 token 移除角色后的有效期和刷新后的权限变化；MDM logout 不可达时本地退出且不声称服务端撤销成功。
- AT-04/09：宽表 → dataset → workitem 按完整键还原实例；检项 ID 不一致、孤立样品和缺数据集明确提示。多个结果行/replicate 的 N、样品数、数据集数分别核算。
- AT-07：用户选结束日包含该日最后时刻，下一日起不包含；固定今天验证 2026-10-02 的 3/6/12 月示例、闰日和月末回溯、Asia/Shanghai 跨午夜、已解析日期冻结、URL/自定义日期优先；旧数据/空结果不悄悄改变默认；源导入偏移独立核对，空 trend_dt 不伪称有效日期。
- AT-11：分别验证 PNG、Excel 和五文件 ZIP；PNG 中文/日期/单位/图例/限度/删失标记清晰，Excel 原值文本单元格含前导零/尾部零/公式字符/中文；CSV 转义和 JSONL 保真可核对。图点数＋未绘图记录与表格行数按分类核算，导出 ID/元数据/四个内容文件哈希正确；滚动日期不在导出时重算，缩放不改变范围；上下文改变提示刷新；渲染或表格生成失败不返回部分下载；Mac/Linux 都验证中文字体。
- AT-13：必需字段丢失明确失败，可选新增列记录差异但不阻断已有查询；result_id 编解码兼容完整源键和数字键类型，不能凭编码绕过来源权限。

以上为初稿复核时的历史结论；2026-10-02 后续已实施 Mac 代码和部分真实验收，未完成项见实际验收记录。
