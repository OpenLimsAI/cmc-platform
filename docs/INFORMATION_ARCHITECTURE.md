## 一张卡片的信息

每张代表一个可独立判断的顶层任务/计划班次，而非每条日志、每张表或每个源文件。仪器归档日班和夜班按独立任务展示，避免最新日班成功覆盖夜班失败；两台仪器及其他子步骤在详情中展开。10个调查顶层组不是全部子任务数或100%覆盖证明。

卡片建议显示：

- 任务名称及小图标；类型/班次作为次级标签。
- 最近观测状态，用颜色、文字、图标共同表达。
- 最近一次已完成执行的结束时间；兜底发现本次未结束时，注明“本次尚未完成”及启动时间/截至本次采集的耗时，历史完成结果标注“上次完成”。
- 本次耗时及一项适用的量：ETL新增/处理行数或备份文件数量/大小；没有可靠指标则不造0。
- 计划简述、下一计划时间；底部较小文字注明最近观测时间。
- 必要的短提示，如“部分文件失败”“恢复未验证”“已恢复，近7天有1次失败”。历史计数仅在证据完整的查询窗口内显示。

卡片内容示意（排版说明，不是真实运行数据）：

```text
仪器文件归档 · 夜班                 备份
已完成，验证不足
最近结束  今日 02:18    耗时 18分钟
完成文件  120个          校验范围见详情
下次计划  明日 02:00
观测截至  今日 07:00     恢复未验证
```

整张卡片可点击/键盘进入详情，焦点清晰；在本项目当前页面打开详情，返回时恢复筛选，回到顶部。没有重跑、恢复、修改调度或清除异常按钮。停用任务仍可进入详情，不将停用与无权限混淆。

## 状态色建议与文字

用户已确认去掉浅蓝，不设置“正在执行”独立卡片状态，主界面展示完成结果。保留浅绿、浅红、浅黄、浅灰四种底色；具体色值及条件为设计建议，判定算法见MONITORING_RULES，详情保留执行、采集及备份验证各自状态。

| 提示 | 浅色底建议 | 卡片文字与条件 |
|---|---|---|
| 本次执行成功 | 浅绿 `#E9F6EE` | 完整任务有可靠成功终止证据，采集有效，没有需要提示的本次风险；显示“执行成功”，不笼统声称所有数据准确或备份可恢复 |
| 失败/确认漏跑/运行超时 | 浅红 `#FCECEB` | 明确原因分开写：“执行失败”“未按计划启动”“运行时间过长”；已经失败仍保留同次原因 |
| 风险/部分失败/验证不足 | 浅黄 `#FFF4D6` | 已完成但耗时偏长、部分失败或质量提醒；备份成功而已有完整性/恢复记录不足可显示“备份完成，验证不足”，执行成功与验证标签独立 |
| 当前未知 | 浅灰 `#EEF1F5` | 读取失败、过期、来源冲突或未接入；旧结果明确标为“最后已知”，不能保持绿色 |
| 已停用/维护 | 浅灰 `#EEF1F5` | 计划状态单独标“已停用/维护”，同时保留最后一次执行及证据；没有批准依据的开关变化另提示 |

任务结束事件正常只带来结束结果；但07:00兜底、监控启动补采或管理员按需采集仍可能看到未结束的任务。未超过耗时上限时以浅灰注明“本次尚未完成”，不能拿上次绿色当本次成功；超过上限并有可靠执行证据则浅红提示“运行时间过长”。这不是实时进度监视，不持续更新运行耗时；相关记录可在详情/历史保留。没有可靠启动证据时按未知处理。

全页基础底色建议`#F5F7FA`，标题沿用Hub深蓝系。上述颜色配合可读深色文本、状态图标及描边；不能只靠红绿识别。悬停/键盘焦点用轻描边提示，不持续闪烁。

最近失败后有同任务同班次的成功，可显示已恢复；历史失败仍在详情与历史摘要中。采集失联时卡片转未知，若最后已知失败，保留故障标签与顶部“最后已知失败，当前未核实”。缺备份验证不会因日志SUCCESS而消失，也不自动触发恢复测试。

## 任务详情

顶部返回总览、名称/类型/班次、当前观测状态及截至时间；概要展示计划、最近尝试/成功、耗时、量和下一计划。下方建议三个内容区：

1. **运行历史**：默认最近7天的逐次执行列表/时间线，列计划/开始、结束、结果、耗时及证据入口；成功、失败、未结束、手工/计划执行区分。点击某次查看该次证据，不混入另一轮日志。2026-10-11修正：点击“查看记录”后自动滚动并将焦点移到所选运行的证据区，展开第一条摘要；重复点击同一记录也重新定位，不要求用户在长表格下方寻找。切换记录显示对应运行时间/状态及原有子步骤，未取得证据明确显示空状态。
2. **执行步骤与证据**：父任务及所有必要子步骤、数据依赖，日志摘要和可展开脱敏片段、水位说明。关联不确定显示歧义/缺失，不自动归入最近管道。
3. **任务说明**：运行计划、来源及读取范围、停用情况、已知覆盖缺口。未拿到负责人或外部策略明确标待补，不虚构。

备份详情增加执行、产物、已有完整性检查、恢复验证四区，分别展示范围/方法/时间/引用。非空dump只支持产物，空hash报告不能支持全量完整，没有演练记录显示“未找到已执行记录”，不显示可恢复。培训同步详情解释是正式库至练习库的数据复制，不是灾备。
