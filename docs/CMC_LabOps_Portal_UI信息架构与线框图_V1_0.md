# 1. 设计原则

## 1.1 设计理念

CMC LabOps Portal 是面向部门人员的内部工具型系统，设计理念与 CMAB MDM Portal 保持一致：

- **工业级而非消费级**：信息密度高于美观度，功能可发现性优先
- **一致性高于创造性**：严格遵循 Ant Design 5 规范，跨模块统一布局和组件
- **渐进信息披露**：列表 → 详情 → 编辑，每层只展示当前任务必要信息
- **参考 MDM 风格**：Header + Sidebar + Content 三栏布局、表格风格、详情页 Tab 风格、状态 Tag 色彩一致

## 1.2 色彩系统

遵循 Ant Design 5 内置色彩 + MDM Portal 统一标准：

| **用途** | **色值** | **使用场景** |
|---|---|---|
| 主色（Primary） | #1F4E79 | 顶部导航、主按钮、链接 |
| 成功（Success） | #52C41A | 状态：在用、合格、有库存 |
| 警告（Warning） | #FAAD14 | 状态：待处理、临近到期 |
| 错误（Error） | #FF4D4F | 状态：已过期、不合格、报废 |
| 默认（Default） | #8C8C8C | 状态：停用 |
| 背景灰 | #F5F5F5 | 页面背景 |

### 状态色映射

| **状态** | **颜色** | **物料** | **设备** |
|---|---|---|---|
| 正常/在用 | 绿 | is_active=true | in_use |
| 停用/退役 | 灰 | is_active=false | out_of_service |
| 送修/校验中 | 蓝 | — | in_repair / in_calibration |
| 报废 | 红 | — | scrapped |
| 已过期 | 红 | expiry_date < today | 校验过期 |
| 临近过期 | 黄 | 30天内 | 校验/保修到期前30天 |

## 3.2 Sidebar 设计

- 默认展开 220px，点击图标折叠到 64px
- 折叠时仅显示图标，hover tooltip 显示模块名
- 当前激活模块左侧 4px 主色边条 + 浅蓝背景
- 二级菜单默认展开当前模块

## 3.3 Header 设计

- 左侧：Logo + "CMC LabOps Portal" 文字，点击回 Dashboard
- 右侧：通知铃铛（告警数红色徽标）+ 用户头像/姓名下拉（个人信息/修改密码/退出）

# 9. 通用组件规范

## 9.1 Ant Design 组件映射

| **场景** | **Ant Design 组件** | **说明** |
|---|---|---|
| 数据表格 | Table | 分页、排序、筛选、行选择 |
| 详情展示 | Descriptions | 4 列分组布局 |
| Tab 分组 | Tabs | 详情页 Tab |
| 状态标签 | Tag | 彩色状态标签 |
| 表单 | Form + Input / Select / DatePicker | Ant Design Form |
| 时间线 | Timeline | 校验/维护/维修记录 |
| 统计卡片 | Statistic + Card | Dashboard 统计 |
| 弹窗确认 | Modal.confirm | 停用/报废等危险操作 |
| 消息提示 | message / notification | 操作结果提示 |
| 面包屑 | Breadcrumb | 页面路径导航 |
| 文件上传 | Upload | 附件上传 |
| 导出 | Button + 前端生成 xlsx | 使用 xlsx 库 |

## 9.2 权限守卫组件

```tsx
// PermissionGuard: 根据用户权限控制 UI 元素显示
<PermissionGuard permissions={['material:create']}>
  <Button type="primary">新增物料</Button>
</PermissionGuard>
```

路由级守卫：ProtectedRoute 组件，未登录跳登录页，无权限显示 403。

## 9.3 响应式规则

- 最小支持宽度：1280px（目标用户均为桌面端）
- 不做移动端适配（内部工具，桌面浏览器使用）
- Sidebar 可折叠以释放内容区域空间
