## 适用范围

- 本文档为 CMC LabOps Portal 的用户需求规格说明
- 覆盖物料库存管理、仪器设备管理、统一平台能力三大模块

- 作为验收测试（UAT）的判定依据

# 1. 项目背景与定位

## 1.1 背景

CMC 部门当前已建成物料库存管理系统（cmc-labops v1.2），覆盖物料导入、入库、出库、移库、盘点、库存查询、预警等核心闭环。系统运行稳定，满足部门日常物料管理需要。

随着部门业务扩展，以下需求日益迫切：

- 仪器设备台账管理：部门拥有大量分析仪器与实验设备，目前依靠 Excel + 纸质台账管理，缺少系统化的计量校验跟踪、维护记录、保修管理、到期提醒

- 统一工作入口：物料管理和设备管理是同一个部门的日常操作，应通过统一门户、统一账号、统一权限访问，而非独立运行

- 前端技术升级：当前 Streamlit 前端在交互复杂度、组件丰富度、权限精细化等方面已接近上限，需迁移到 React + Ant Design 以支撑更复杂的业务场景

## 1.2 系统定位

| **维度** | **说明** |
|---|---|
| 系统名称 | CMC LabOps Portal（CMC 部门运营平台） |
| 定位 | 部门级日常操作系统，面向 CMC 部门全体人员 |
| 与 MDM 关系 | MDM 是公司级主数据权威源；LabOps Portal 是部门级操作系统，不复制 MDM 的 Substance/Project/Asset 管理能力 |
| 核心模块 | 物料库存管理、仪器设备管理 |
| 统一能力 | 统一入口、统一认证、统一权限、统一审计、统一导航 |
| 用户群体 | CMC 部门研发人员、库管人员、设备管理员、部门负责人 |

## 1.3 与 MDM 的边界

| **能力** | **MDM Portal** | **LabOps Portal** |
|---|---|---|
| 物质/分子身份管理 | ✓ 权威源 | ✗ 不涉及 |
| 项目/药物资产登记 | ✓ 权威源 | ✗ 不涉及 |
| 物料主数据（V1.2） | ✓ 权威源（mm.material） | 运营快照，入库时按编码拉取 |
| 设备主数据（V1.2） | ✓ 权威源（eqp.equipment） | 运营台账，建档时按编码拉取身份字段 |
| 部门日常物料出入库 | ✗ 不涉及 | ✓ 核心能力 |
| 批次级库存与预警 | ✗ 不涉及 | ✓ 核心能力 |
| 设备运营（状态/位置/负责人） | ✗ 范围外 | ✓ 核心能力 |
| 计量校验/维护/维修/保修/附件 | ✗ 范围外 | ✓ 核心能力 |
| 用户认证 | 统一权威源（签发 JWT） | 复用 MDM 认证（V1.1：登录代理 MDM，本地校验 JWT，不建用户表） |
| 审计追踪 | Part 11 合规级 | 部门操作级（非 GMP） |
