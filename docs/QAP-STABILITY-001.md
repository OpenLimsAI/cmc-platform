# 稳定性页面实施记录

2026-09-16，Mac本机续建。依据旧项目实际的 stability_sidebar、stability_plots、data_fusion 和 plot_area；设计目标不视为已实现功能。

## 设计与范围

延续放行页：标题蓝 #1A5276、组别蓝 #1f77b4、正文 #1B2631、浅灰侧栏 #f5f7fa、白色画布 #ffffff；PingFang SC/微软雅黑，正文14px、页标题26px、检测项标题18px。左侧筛选，右侧指标组合及按检测项排列的图表；每项切换逐批观察、组均值/SD、逐批拟合、组拟合，下方为可展开原始记录。筛选与结果范围保持可见，窄屏收起筛选。

```text
项目 / 样品 / 类别 | 稳定性趋势 + 当前数据范围
产线 / 组别 / 批号 | 常用指标组合
检测项            | 检测项 / 样品 / 类别 / 方法 / 原始单位
分析 / 重置       | 逐批观察 | 组均值SD | 逐批拟合 | 组拟合
                  | 图表、描述统计、完整原始记录
```

复核：延续旧版以时间趋势和批号比较为主的工作区，复用既有图表栈；不另做通用后台样式。不自动给批次冠以实验/对照身份。

## 数据边界

- 继续只读cmc_analytics共享staging。可选择研发LIMS或QC历史staging，单次仅一个来源。RD分类沿用CSV/启发式；QC只读取来源明确写“稳定性”的记录，尚不是业务批准状态。项目选项数量应明确是来源记录，不冒称全是稳定性。
- 本机只读复核：31790条稳定性数值结果、55个项目；时间单位为空28782条、天2944条、月64条。时间点能转为数值且非负，但不据此猜测单位；不能把空单位当月。该计数为本次快照。
- 图表按检测项、来源检测项、样品、检验类别、方法、结果单位、时间单位分面；不同面不合并。逐批系列还区分来源、产线、组别；同时间点多个观察均保留，出现重复时间点时逐批观察图只画点，避免暗示复测顺序。缺失批号不连成一个批次。
- 不覆盖原值、不自动去重、不按_pct字段乘100、不换算时间单位。缺失/非法时间或值保留在明细，并列出不能入图的原因。单位缺失时可看原始观察，但不开放均值SD或拟合。
- 组均值/样本SD按同一面内产线+组别+来源、每个时间点的观察数计算；N为观察数，不代表独立批次数。单点SD为空。线性拟合仅描述已观察时间范围，至少两个不同时间点；不推断有效期、合格、等效或统计显著性。
- 旧版Day-0融合会改写放行时间/时间单位，现有字段也无稳定性研究/储存条件标识，不能直接迁移为正式规则。本轮不读取放行结果作补点。对照/实验定义、Day-0来源与配对、研究/储存条件字段、单位和规格版本待确认。
- LME、TOST、规格/能力指数和有效期预测不纳入本轮，不把旧算法对照测试当业务验收。稳定性页面不写数据库，也不产生批准结论。

后续QC接入及最新验证见 [来源记录](QAP-DATA-SOURCES-001.md)；以下为初次稳定性开发批次证据。
