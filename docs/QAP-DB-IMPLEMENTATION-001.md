## 4. Mac 验证流程（批准后）

1. 记录目标数据库、host/port、当前 revision、唯一 head、中央 Git commit、迁移文件 hash、schema/索引/FK/视图/函数/ACL 指纹。查询前确认连的是 Mac rd_pg，禁止凭 .env 名称猜环境。
2. 完成本机共享 cmc_analytics 备份、旧 Excel 原文件与兼容配置备份，权限受控且不进 Git；保存各在用对象计数/校验摘要。Mac 已有数据，禁止清空重建。
3. 验证备份可读并做同机隔离恢复演练（受批准范围约束），核对 revision/对象/行数/hash。仅 pg_restore --list 不算恢复成功。演练环境不作为新业务数据库，也不持久新建 Mac 培训库。
4. 中央仓库产生**明确版本范围**的离线 SQL，检查新增对象、锁、超时、角色影响。避免不带起点的全历史 `upgrade head --sql`。按包测试并优先使用事务型 DDL，明确 lock_timeout/statement_timeout；超时停止，不终止其他系统连接抢锁。
5. 执行批准的结构迁移，记录 current 与预期 revision；在数据作业前确认空新表结构、约束、权限、视图。
6. 用合成/经批准的本机样例跑导入与分析；来源回填先输出计数、问题数和待纳入集合，审批后执行；单位、规格或批准不明保持未评价/探索，不借迁移自动“修好”。
7. 做 §7 验收，旧表指纹、数据和旧看板均须保持可用。通过后提交中央迁移及应用依赖，才进入 Linux 申请。

旧 Excel 写口切换单独评审：先保留旧读写并做一次明确截止点的只读试回填，不将试回填视为最终当前集；最终切换窗口暂停旧导入和新导入，记录旧 id/文件hash/结果计数，对照截止点补齐变更和删除重建关系，无法对账时停止。确认后仅启用新写口，旧看板继续读冻结兼容表并明确数据截止时间，或经独立适配改读正式消费视图；“保留可用”不冒充实时更新。若必须同时实时供给两套看板，需另做单一写入口下的受控兼容投影并验收，不能两边独立 DELETE/INSERT。切换后的回退也须停写对账，禁止恢复旧写口覆盖新历史。

离线预览命令形式（示意占位，不可直接复制执行）：

```text
./dbmig cmc_analytics upgrade <已复核当前revision>:<批准目标revision> --sql
./dbmig cmc_analytics current
```

实际 upgrade 不带 --sql 是写入操作，执行前向负责人给出对象、影响、备份位置及回退方式并确认。本轮未运行这些命令。

## 5. Linux 正式/培训库同步（另行批准后）

Linux 为原生 PostgreSQL，应用部署在 `/opt/cmc-quality-analytics-platform`，systemd 常驻；不得覆盖 `/opt/quality-analysis-platform`。流程为 Mac 修改并验证→Git push→Linux pull→批准窗口迁移。Linux 业务数据、备份和恢复演练均留在 Linux，不下载到 Mac。

### 5.1 培训库隐藏依赖

静态发现：`rd-batch-registry/scripts/training_db_reset.sh` 从正式库整库 dump（**包含数据及 alembic_version**）建立新培训库，只停批号培训服务，终止培训全库连接后换库并删除旧库；文档称每日 00:00 执行。**本轮未确认 Linux 定时任务是否仍启用。**

上线前必须在 Linux 本机只读确认该作业和所有培训消费者，并评审调整：

- 验证窗口暂停自动重置，记录恢复安排，否则新结构/验收样例可能被夜间旧正式库覆盖。
- 正式员工审计/质量数据/文件路径不得因整库复制就默认为培训可用数据；确认培训允许的数据范围及脱敏策略。
- 培训使用独立文件存储、凭据与审计；数据库复制不等于 Excel 文件复制，不允许培训下载入口指向正式文件区。
- 同步所有培训应用的停写/恢复，不仅批号系统；既有脚本的换库删除行为不在本轮授权内。
- 培训运行日志和导入证据是否可被周期重置清除需明确；迁移验证期留存证据不能丢。
- 角色是实例级的，dump/restore 和同名角色不能保证环境隔离；恢复后重验 CONNECT、ACL、角色继承、sequence/函数权限。

这些是上线门槛，不是本轮自动停止或修改作业的授权。

### 5.2 窗口顺序

1. Linux 本机重新只读核查正式/培训 current、代码 commit、对象指纹、权限、一期角色是否已存在；漂移停止，不能 stamp 掩盖。
2. Linux 本机备份正式/培训数据库和各自文件、记录角色配置/ACL/版本；完成隔离恢复校验。确认培训重置作业维护窗口。
3. 培训库使用**同一 cmc_analytics 迁移目录和相同目标 revision**。先批准的培训迁移及合成样例验收；无 Mac 业务数据上传、无生产业务数据下载到 Mac。
4. 通过后在正式窗口执行相同已审查范围；先只读/关闭新导入上线，验证旧消费者，再逐项开启新入口。迁移和应用 feature 开关版本绑定。
5. 最终比对 Mac/正式/培训的目标 revision 与对象结构、约束、函数、索引；权限按职责/环境比对。数据和文件各自独立，不要求行数相同、不作反向同步。
6. 按批准的改进方案恢复培训重置作业，验证重置后 QAP 服务/存储/ACL仍正确；未经完成这一步不能宣称培训环境长期就绪。

## 6. 备份与回退

白皮书 R&D/Analytics 目标 RPO≤24小时、RTO≤8小时；这只是目标，恢复时间和数据丢失窗口须演练确认。变更前即时备份作为本次恢复点，定期备份不能替代它。

备份清单：数据库一致性快照（结构+数据+序列+版本）、角色/授权受控登记、原始文件和文件登记对应 hash、应用/迁移 commit、配置安全备份、字典/规格 manifest。密码/令牌不写进文档、Git或公共日志。数据库快照与文件区在暂停导入或确定一致截止点后配对，检查每个已发布文件引用均可恢复。

| 故障阶段 | 首选动作 | 禁止动作 |
|---|---|---|
| 事务型 DDL 未提交 | 回滚失败迁移，保留日志，确认版本未前进 | 手改版本表或继续跑后继迁移 |
| DDL 已提交、尚未用新结构 | 关闭新功能，旧应用继续运行；优先追加修复迁移 | 为“回到原状”直接删共享对象 |
| 新导入/事实已发布 | 停新写入，保留全部历史；回退兼容应用读取路径，或受控新数据集撤回错误成员 | DELETE 原值、按文件名覆盖、随便倒退 dataset_head 而丢掉后续正常导入 |
| 字典/规格有误 | 发布纠正版本，固定旧分析证据；重评价另存新结果/数据集 | 改旧规格让历史结论悄然改变 |
| 必须恢复备份 | 先保存故障现场及备份后的增量；在同机隔离恢复，核验并经专项批准选择性修复/切换 | 覆盖整个共享库而丢掉其他系统的后续业务 |

一期 downgrade 主动拒绝删除，不能强行绕过。新迁移涉及审计/事实留存时，downgrade 默认拒绝销毁已有数据并说明恢复路径；只有明确空表且无依赖、经批准的场景才考虑结构撤销。备份存在不等于可以未经确认 DROP/重建。

## 7. 验收清单（尚未执行）

| 范畴 | 必须证明 |
|---|---|
| 保留兼容 | 既有 LIMS staging、旧 quality、其他共享对象结构/数据不变；旧看板和 ETL 查询可用，ETL 新鲜度按 job_name 查看 |
| 批号 | 原值不变，>32/空值可定位阻断；不新增同义 batch_id；源和内部数字键不受影响；跨源 JOIN 不倍增 |
| 粒度 | 同批同指标的平行/复测/时间点都保留，复测关系与更正链分开；一来源观察在一个数据集只一个生效版本；head不可跨范围/指向draft，分析输入必须属于该运行集合 |
| 单位/规格 | 比例/百分数、方法混名、单双侧限、开闭边界、单位不明、有效期交界/重叠、多匹配、无规格均有经确认期望；不自动批准/换算；规格/映射状态有效期变更有同事务前后值审计 |
| 文件/预览 | file hash 校验、原文件可恢复、sheet/行/列定位、警告/错误完整；规则或文件改变、预览过期都不能直接提交 |
| 事务/并发 | 中途失败不部分发布；重试/同文件异名/同名同内容/跨文件重叠均可审计；两个员工竞争更正同一旧版本只能一个成功 |
| 更正/撤回 | 旧值、旧文件、员工和理由可查；不把修订文件缺行当删除；撤回保留后续无关正常结果；旧报告按原 dataset 重现 |
| 身份/权限 | MDM 无效/过期令牌、type不符、临时密码须改标记、无导入角色、跨项目访问均拒绝；不能伪造员工；正式必需配置缺失启动失败 |
| 数据库权限 | 实际 reader 尝试 INSERT/UPDATE/DELETE/DDL 被拒；写服务不能改共享 staging/raw/MDM/历史事实；培训写凭据不能操作正式库；审计不可改删 |
| 统计 | 手工核对小样本、独立实验单位、混合模型组名置换/排序不变、方法/样品/单位混组拒绝；不仅与旧函数输出对照 |
| 环境与恢复 | 同链同目标结构；培训重置后仍正确隔离；数据库+文件恢复通过，记录实际 RPO/RTO |

读账号拒写测试必须使用受控测试对象和事务，不能对共享真实业务表执行可能成功的破坏性语句。所有测试状态据实际结果填写，不因已有单测通过而勾选。
