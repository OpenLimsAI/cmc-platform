# MDM 与 PM：第一阶段已有项目一对一关联

2026-10-26。负责人已确认：MDM 管登记与治理，PM 管执行；一个登记项目对应一个 PM 执行项目，阶段与工作包留在该 PM 项目的 WBS 中。已授权本地开发、草稿PR，以及真实E2E与CI全部通过后的合并；不含生产部署、真实身份改造或对已有数据库执行迁移。

## 实施边界与清单

- [x] 在 MDM 的 prs schema 增加项目关联表及独立 Alembic 迁移。两端 ID 分别唯一，保留双方原 ID。
- [x] 使用现有 project:read / project:update 权限保护查询与绑定；绑定只接受 PM ID 和原因，不接受名称自动匹配或自报的 PM 摘要。
- [x] PM 提供按现有用户数据范围保护的项目只读引用接口；MDM 通过单独配置的 PM 项目核验访问令牌核验项目，绝不转发 MDM 登录令牌。
- [x] 相同项目对重复提交返回原关联，不重复写审计；两端任一冲突返回409；数据库唯一约束与事务锁共同防并发冲突。

- [x] 覆盖权限、重复/冲突、项目缺失/失效、配置缺失、URL安全、令牌不进入响应和URL，以及迁移约束；报告实际执行和未执行部分。

## 数据契约

关联由 MDM 拥有：prs.project_pm_link 保存 MDM project_id、PM项目ID、从PM取得的编号/名称快照、核验时间、建立时间、MDM操作者ID和建立原因。PM 不另建一份可修改映射，不跨库查询或写入。关联本轮不可直接改绑/删除；解除和历史迁移另立流程。

不传输或覆盖状态、计划、团队、预算、负责人；MDM身份ID、历史审计和密码签名保持现有实现。远端项目可用性是核验时点事实，跨库不承诺原子一致；读取时再次核验，缺失、不可用或归档明确显示。

## 配置与权限

PM_PUBLIC_URL 是 PM 浏览器入口的受控 origin。PM_REFERENCE_API_URL 是 PM API 的受控 origin，PM_REFERENCE_ACCESS_TOKEN 只接受另行批准提供的有效 PM 项目核验访问令牌，保持空值默认关闭；本轮不创建正式服务账户、OAuth客户端或持续凭据。用户另行明确批准的本机隔离 Casdoor 临时客户端和合成验收身份仅用于此次真实验收，结束即撤销。远端请求超时、有界响应、不跟随重定向、不使用系统代理，不把令牌写入日志或返回前端。

PM端 MDM_PUBLIC_URL 是受控MDM页面根地址（含 /mdm/），默认空值。入口不证明拥有MDM业务权限，MDM仍独立登录、验签并授权。深链只含项目ID/编码，不携带身份或令牌。Casdoor SSO和Hub退役均属于后续阶段。

## 验证与回退

只在明确新建、独立容器/卷/网络的测试环境执行迁移和测试，不使用仓库Compose的固定容器/卷或未知现有库；测试仅使用合成身份和数据。PM既有SQLite测试也必须使用新建临时文件，禁止继承外部TEST_DATABASE_URL。没有安全环境时保留测试并说明未运行，不关闭鉴权。

回退先关闭新入口和跨系统核验配置，保留已有关联。新表含关联时downgrade拒绝删除，避免静默丢失映射；只有空表可移除。完全回退代码前必须协调数据库迁移版本，因为旧版启动检查不接受未知的新迁移；不得用stamp或删除映射绕过检查。MDM与PM原业务数据不因关闭入口改变。后续outbox/inbox扩展以该唯一映射为基础，另定义幂等事件、版本及冲突处理。
