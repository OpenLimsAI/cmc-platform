## 初始化问题与修复

1. Casdoor 首次启动创建内置管理员后，`initDataNewOnly=true` 跳过了该管理员随机密码覆盖。两次正常登录失败后停止尝试。仅对本轮全新合成环境调整初始化，再启动该临时 IdP；未修改真实账号、未猜测默认密码。
2. Docker `--tmpfs` 信息出现在 `HostConfig.Tmpfs` 而非 `Mounts`；保护检查曾暂停初始化。只读核对确为 tmpfs 且无其他 Mounts 后修正检查继续。
3. 首轮门户用了 localhost、IdP 为 127.0.0.1，门户成功登录却没有跨站点 SSO。仅将临时门户回调/公开地址统一为 127.0.0.1，复验免重复输入成功；**未改变浏览器 Cookie 或安全设置**。
4. 验收脚本曾写错公开配置断言键，实际服务已切换；先只读确认 `native_login_enabled=false`，再仅重放请求，没有重复切换或重复签发来冒充首轮通过。
