# 两库盘点与对比操作手册

> 目标：在 Mac (Docker) 和 Linux VM 上各跑一次 `export_postgres_inventory.py`，
> 把两份 `inventory_full.json` 都拿到 Windows (`F:\Python\sql\`)，再运行
> `compare_pg_inventory.py` 看两边结构差异。

---

## 0. 整体流程一图

```
┌──────────────────┐  scp / git pull  ┌─────────────────────┐
│ Mac (Docker PG)  │  ───────────────▶│ F:\Python\sql\      │
│ 跑盘点脚本        │                   │ pg_inventory_mac_…  │
└──────────────────┘                   │                     │
                                       │ pg_inventory_linux_…│
┌──────────────────┐   scp from Win    │                     │
│ Linux VM (PG16)  │  ◀────────────────│ 在 Windows 上对比    │
│ 跑盘点脚本        │                   │ → diff_xxx.md       │
└──────────────────┘                   └─────────────────────┘
```

预计耗时：第一次走完 30~60 分钟，主要花在环境检查上；以后每次 5 分钟。

## 1. 公共前置：脚本怎么到达 Mac 和 Linux

`export_postgres_inventory.py` 现在在 Windows 的 `F:\Python\sql\` 下。要把它送到 Mac 和 Linux，有两种方式，任选其一：

### 方式 A：通过 SCP 直接传（推荐，最省事）

在 Windows PowerShell 中：

```powershell
# 送到 Linux（替换 user 和 IP）
scp F:\Python\sql\export_postgres_inventory.py prometheus@172.19.0.105:~/

# 送到 Mac（需要 Mac 上启用「系统设置 → 通用 → 共享 → 远程登录」）
scp F:\Python\sql\export_postgres_inventory.py user@<mac-ip>:~/
```

### 方式 B：通过 Git

如果你的 git 仓库里包含 `F:\Python\sql\` 这个目录，那 push 一次，到 Mac 和 Linux 上 `git pull` 即可。

> ⚠️ 注意：盘点产物 (`pg_inventory_*` 目录) 体积可能很大，**不建议把这些产物 commit 进 git**，否则仓库会越来越大。把 `pg_inventory_*` 加进 `.gitignore`，产物通过 scp 单独传。

## 2. 在 Mac (Docker) 上跑盘点

### 2.1 第一步：搞清楚 Docker 容器和端口

打开 Mac 终端，先看看容器在不在跑：

```bash
docker ps
```

输出大概长这样：

```
CONTAINER ID  IMAGE          ...  PORTS                    NAMES
a1b2c3d4e5f6  postgres:16    ...  0.0.0.0:5432->5432/tcp   my-postgres
```

**记下两个东西**：
- 容器名（最右列，本例 `my-postgres`）
- 端口映射（PORTS 列中 `主机端口->容器端口`，本例主机端口是 `5432`）

如果容器没在跑：

```bash
docker start <容器名>
```

如果你完全找不到容器（之前都是 `docker-compose` 起的）：

```bash
docker ps -a   # 看所有容器（含已停止）
# 或进到你的 compose 项目目录
cd <你 docker-compose.yml 所在目录>
docker compose up -d
```

### 2.2 第二步：检查 Mac 主机有没有 Python + psycopg

Mac 一般自带 Python 3。检查：

```bash
python3 --version
```

如果显示版本号（≥ 3.8）就行。

然后看 psycopg 装没装：

```bash
python3 -c "import psycopg; print(psycopg.__version__)"
```

如果报 `ModuleNotFoundError`，装一下：

```bash
# 推荐用虚拟环境（避免污染系统 Python）
cd ~
python3 -m venv pg-inventory-venv
source pg-inventory-venv/bin/activate
pip install psycopg[binary]
```

> 以后每次跑前都要先 `source ~/pg-inventory-venv/bin/activate`。

### 2.3 第三步：跑盘点脚本

假设 Docker 端口是 5432，postgres 用户密码是 ` YourStrongPassword_2026`：

```bash
cd ~                            # 或脚本所在目录
PGPASSWORD=YourStrongPassword_2026 python3 export_postgres_inventory.py \
  --host 127.0.0.1 \
  --port 5432 \
  --user postgres \
  --maintenance-db postgres \
  --outdir ./pg_inventory_mac_$(date +%Y-%m-%d)
```

跑完会生成一个目录 `pg_inventory_mac_2026-05-13/`（日期会变），里面有 `inventory_full.json`、`inventory_report.md` 和 `csv/`。

### 2.4 第四步：把结果传回 Windows

最简单的方法：在 **Windows PowerShell** 里拉过来：

```powershell
# 进入工作目录
cd F:\Python\sql\

# 从 Mac 把整个盘点目录拉回来
scp -r user@<mac-ip>:~/pg_inventory_mac_2026-05-13 .
```

如果 Mac 没启用远程登录，反向操作：在 Mac 上把目录推到 Linux，再从 Windows 拉。但更建议你直接在 Mac 上启用一下「远程登录」（系统设置 → 通用 → 共享 → 远程登录开关打开），一次性解决。

## 3. 在 Linux VM 上跑盘点（通过 SSH）

### 3.1 第一步：SSH 进 Linux

在 Windows PowerShell：

```powershell
ssh user@<linux-ip>
```

进去之后你就在 Linux 命令行里了。

### 3.2 第二步：检查 Python + psycopg

Ubuntu/Debian：

```bash
python3 --version

# 如果没装 Python：
sudo apt update
sudo apt install -y python3 python3-pip python3-venv
```

装 psycopg（强烈建议用虚拟环境，Ubuntu 24+ 的系统 Python 会拒绝直接 pip install）：

```bash
cd ~
python3 -m venv pg-inventory-venv
source pg-inventory-venv/bin/activate
pip install "psycopg[binary]"
```

以后每次连进来要先：

```bash
source ~/pg-inventory-venv/bin/activate
```

### 3.3 第三步：确认脚本已到 Linux

如果你刚才用 scp 推过来了，应该在 `~/export_postgres_inventory.py`：

```bash
ls -lh ~/export_postgres_inventory.py
```

没有的话回到 Windows 重新 scp。

### 3.4 第四步：跑盘点脚本

**先尝试 peer 认证（不需要密码）**，因为默认 Ubuntu 装的 PG，本机 postgres 系统用户走 peer：

```bash
sudo -u postgres bash -c '
  source ~/pg-inventory-venv/bin/activate 2>/dev/null || \
  source /home/<你的用户名>/pg-inventory-venv/bin/activate
  python3 /home/<你的用户名>/export_postgres_inventory.py \
    --host /var/run/postgresql \
    --port 5432 \
    --user postgres \
    --maintenance-db postgres \
    --outdir /tmp/pg_inventory_linux_'$(date +%Y-%m-%d)
'
```

注意 `--host /var/run/postgresql` 是走 Unix socket，这是 peer 认证的关键。

**如果 peer 不行（脚本可能不支持 socket 路径），改走密码：**

先确认有密码，给 postgres 设个密码：

```bash
sudo -u postgres psql -c "ALTER USER postgres WITH PASSWORD 'tt_postgres';"
```

然后正常跑：

```bash
cd ~
source pg-inventory-venv/bin/activate
PGPASSWORD=tt_postgres python3 export_postgres_inventory.py \
  --host 127.0.0.1 \
  --port 5432 \
  --user postgres \
  --maintenance-db postgres \
  --outdir ./pg_inventory_linux_$(date +%Y-%m-%d)
```

> 如果连 127.0.0.1 提示 `password authentication failed`，编辑 `/etc/postgresql/16/main/pg_hba.conf`，找 `host all all 127.0.0.1/32 ...` 那一行，确认是 `md5` 或 `scram-sha-256`，然后 `sudo systemctl reload postgresql`。

跑完应该看到：

```
✅ inventory written under ./pg_inventory_linux_2026-05-13
```

`exit` 离开 SSH 回到 Windows。

### 3.5 第五步：把结果从 Linux 拉回 Windows

在 Windows PowerShell（**不在 SSH 里**）：

```powershell
cd F:\Python\sql\

# 假设 Linux 上目录在 ~/pg_inventory_linux_2026-05-13
scp -r user@<linux-ip>:~/pg_inventory_linux_2026-05-13 .

# 如果你刚才用的是 /tmp/ 路径
scp -r user@<linux-ip>:/tmp/pg_inventory_linux_2026-05-13 .
```

> 第一次 scp 会问你确认指纹，输 `yes`。如果嫌每次都输密码烦，配 SSH 公钥认证：`ssh-keygen` → `ssh-copy-id user@<linux-ip>`（Win11 上有 ssh-copy-id 的话；没有就手动把 `~/.ssh/id_rsa.pub` 内容追加到 Linux 的 `~/.ssh/authorized_keys`）。

## 4. 在 Windows 上跑对比

文件齐了之后，目录大概长这样：

```
F:\Python\sql\
├─ export_postgres_inventory.py
├─ compare_pg_inventory.py
├─ pg_inventory_mac_2026-05-13\
│  └─ inventory_full.json
├─ pg_inventory_linux_2026-05-13\
│  └─ inventory_full.json
└─ ...
```

在 PowerShell：

```powershell
cd F:\Python\sql\

python compare_pg_inventory.py `
  pg_inventory_mac_2026-05-13\inventory_full.json `
  pg_inventory_linux_2026-05-13\inventory_full.json `
  --database cmc_data_platform `
  --left-label mac `
  --right-label linux `
  --out diff_mac_vs_linux_2026-05-13.md
```

> Windows 上没有可用 Python？装一个：[python.org/downloads](https://www.python.org/downloads/)，安装时勾上 `Add Python to PATH`。这个对比脚本只用标准库，无需额外装包。

打开 `diff_mac_vs_linux_2026-05-13.md`，第一段就是「差异概览表」，一眼看出问题严重程度。把这个文件内容贴给我，我们一起决定怎么处理每条差异。

## 5. 常见问题

### Q1：`docker ps` 看不到 Postgres 容器

容器可能停了。先 `docker ps -a` 看历史容器，找到名字后 `docker start <name>`。或者你本来用 `docker compose`，到 compose 目录跑 `docker compose up -d`。

### Q2：Mac 上 `python3 export_postgres_inventory.py` 报 `connection refused`

Docker 端口没暴露到 Mac 主机，或端口不是 5432。回到 §2.1 看 `docker ps` 的 PORTS 列。也可以 `lsof -iTCP:5432 -sTCP:LISTEN` 确认 5432 有人监听。

### Q3：Linux 上 SSH 进去后，`python3` 报「command not found」

最小化 Ubuntu 镜像可能没装。`sudo apt install -y python3 python3-venv` 解决。

### Q4：Linux 上 `pip install` 报 `externally-managed-environment`

Ubuntu 23.04+ 的限制。**别加 `--break-system-packages`**，老老实实用虚拟环境（§3.2 里的步骤）。

### Q5：SCP 卡住或被防火墙拦

Linux 上确认 `sudo ufw status`，如果开着确保 22 端口开放。或者你可以在 Linux 上压缩后通过 Web 方式拿：

```bash
cd ~
tar czf inv.tgz pg_inventory_linux_2026-05-13
python3 -m http.server 8000   # 临时起个 HTTP 服务
```

然后在 Windows 浏览器访问 `http://<linux-ip>:8000/inv.tgz` 下载。下完到 Linux 终端 Ctrl+C 关掉。

### Q6：盘点目录体积大，传得慢

只传你最关心的那个文件就够了，对比脚本只需要 `inventory_full.json`：

```powershell
scp user@<linux-ip>:~/pg_inventory_linux_2026-05-13/inventory_full.json `
    F:\Python\sql\pg_inventory_linux_2026-05-13\inventory_full.json
```

（在 Windows 这边记得先 `mkdir pg_inventory_linux_2026-05-13`。）

### Q7：两边盘点的「截止时间」对不齐，会不会有问题

对比的是**结构**不是数据。只要你跑盘点的时候没人在改库（DDL），相差几小时无所谓。如果你正好在做迁移，跑盘点前先停掉应用更稳妥。
