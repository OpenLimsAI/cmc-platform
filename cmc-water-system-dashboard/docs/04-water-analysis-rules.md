## 0. 两页统计范围

独立期间汇总和数据质量功能已按用户要求删除。总览仅保留WFI/PW/PS三卡片：点位数按全部可用入选结果中非空内部ID去重，年度样品按当前自然年1月1日至上海今天去重，状态固定Reviewed，规则版本water_overview_counts_v2。年度日期为空不计样品；缺点位仍可计年度样品；空数据补零，查询失败报错。趋势继续现有滚动筛选、解析/比较组与导出规则。详见[两页整理记录](changes/20261009-two-page-dashboard.md)及docs/07。

位置与系统归属暂停，等待用户对照表；点位数不能解释为独立水系统数。

## 1. 规则层次与版本

来源参数选择复用 `water_system_v2` 与 `water_conductivity_method1_numeric_v2`（兼容旧 v1）；本项目新增的展示、解析和统计规则采用独立版本，当前代码版本 `water_dashboard_analysis_v2`。规则与统计隔离测试及历史抽样有记录，正式业务确认/用途验证仍未完成。

每个结果保留上游选择规则及原值。方法规则变更由上游维护；本项目调整分析口径时，记录旧/新定义、影响范围和对账证据。

## 2. 上游已有最终参数口径

| 检项 | 现有上游口径 | 看板处理 |
|---|---|---|
| pH | v1 `结果` | 精确数值可作趋势，方法分组 |
| 不挥发物 | v1 `残留残渣` | 先核对数值格式和单位 |
| 亚硝酸盐、氨、硝酸盐、重金属 | 对应 v1/v2 `结论` | 定性分类与原文明细 |
| 外观、性状 | 对应版本 `结论` | 定性分类与原文明细 |
| 微生物限度 | v1/v2/v3 `报告值` | 区分精确值与 `<1` 等删失值 |
| TOC | v1 `TOC报告值`、v2 `结果` | 单位/方法比较组确认后作趋势 |
| 电导率 | 普通方法 `结果`；旧纯化水按上游规则选报告值/结果；方法1保留结论并补数值 | 数值趋势与结论分别展示，同一次检测不重复计数 |
| 细菌内毒素 | v1/v2 `结论` | 先展示定性结果；不把试剂量/限度当实测值 |
| 酸碱度 | v1/v2 `结果判定` | 定性结果 |

表为上游规则摘要，准确的 `paramlistid/version/variant/param` 条件以 QC 代码为准。不得根据检项名称正则扩展最终结果选择范围。

## 3. 状态、期间与计数

上游水系统宽表仅包含 `Reviewed` 且参数 `releasedflag=Y`；`Completed` 为测完未复核，`Reviewed` 为样品已复核状态。样品状态不能单独证明 QA 身份或产品放行，参数已发布也不等于样品/批次已放行。趋势、原文表、导出和总览仅纳入 `Reviewed`；API 拒绝 `Completed`。未审核参数不在水系统最终结果表内。

期间采用 `trend_dt`。页面起止日期均包含用户选中的日历日；API FilterSpec 使用亚洲/上海日期 `date_from`（包含）和 `date_to`（不包含），前端把页面终止日转换为下一日作为 date_to。后端将日历边界构造为Asia/Shanghai带时区时间用于查询。已核对 staging 时间列在迁移中为 timestamptz，但仍须核实源时间和导入时区，数据库类型本身不能证明源采样时刻正确。月/季度/年边界统一使用同一规则。

趋势日期默认及快捷规则：

- 没有指定日期的首次进入，按后端 context 的 Asia/Shanghai `current_date`，选择当天向前 12 个日历月至当天；两端日期包含。
- “季度趋势（近 3 个月）”“半年趋势（近 6 个月）”“年度趋势（近 12 个月）”均截至今天，按日历月回溯；这是趋势滚动范围；总览年度计数使用自然年，与近12个月范围不同。
- 保留自定义起止日和 URL 恢复的明确日期；已指定日期优先于默认范围。月末或闰日回溯时，落到目标月最后一个有效日，不按固定 90/180/365 天替代。
- 初次进入或点击快捷范围时解析并固定实际起止日；查询和导出沿用这组日期，跨过午夜不自动改变已选范围。再次点击快捷范围时取得后端最新 current_date，再按今天重新计算，避免使用昨日缓存。
- 示例今天为 2026-10-02：季度为 2026-07-02～2026-10-02，半年为 2026-04-02～2026-10-02，年度/默认为 2025-10-02～2026-10-02；三者 API date_to 均为 2026-10-03。
- 不用最新结果日期替代今天。历史快照在默认范围无结果时明确显示无结果和真实数据上下文，用户可自行改日期；不能静默切换为数据最后一年的范围。

`trend_dt_source` 必须随数据显示。横轴标“趋势日期”，只有确认 `collectiondt/eventdt` 的业务语义后才可标“采样日期”。无有效日期的结果不能进入所选期间，也不放到伪造日期；独立质量明细功能已删除。

| 指标 | 定义 |
|---|---|
| 入选样品数 | 趋势筛选后宽表中唯一 `(source_system,s_sampleid)` 数；总览年度样品另按固定年度口径统计 |
| 结果行数 | 完整结果复合键的唯一行数 |
| 方法数据集数 | `source_system,sdcid,keyid1,keyid2,keyid3,paramlistid,paramlistversionid,variantid,dataset` 唯一组合数 |
| 检测次数 | 只有完整检项实例身份已核对才能计算；身份未确认时显示“方法数据集数”，不能替换标签 |

电导率方法1的 `结果` 与 `结论` 属于同一数据集；计方法数据集数时去除参数维度。重复/复测与源 replicate 保留，不擅自按样品取 MAX、平均或最后一条。

## 4. 数值解析与可比组

原始 `displayvalue` 与 `unit` 永远保留。派生 `result_kind` 分类为 `exact_numeric/censored/qualitative/missing/unparsed`，派生数值使用 Decimal 精度；分类与失败原因能回查。

- 精确数值：只接受核对过的数字格式；保留有效数字展示，不用浮点格式覆盖原文。
- 删失值：`<1`、`≤...`、`>...` 等保存比较符和界值，未定统计策略前不纳入普通均值/标准差。图中使用独立标记；微生物限度最终报告值的小于号阈值恰为 1 时 plot_value=0（water_microbiology_lt1_zero_v1），精确 1 仍为 1，原文和阈值保留。其他删失继续按界值绘图；删失绘图值均不是实测点。
- 定性值：符合规定、未检出等保留原文；分类映射需要版本，不因文字正则自行产生“合格率”。
- 空值与未解析：分别计数、显示原值和原因，不当 0，不静默删除。
- 当前派生数值只解析displayvalue，不使用enteredvalue/transformvalue替代，也未实现数值/文字矛盾的自动判定。源字段保留供追溯；以后若采用替代来源或差异判断，须先核对具体方法。
- 当前定性白名单为符合规定、合格、未检出、不符合规定、不合格、无色澄清液体、无色透明液体；其余非数字原文为unparsed。解析只去首尾空白，源值仍原样保留。

当前比较组精确包含samplesubtypeid、samplepointid、workitemid、paramlistid、paramlistversionid、variantid、paramid、paramtype、unit九个源字段；按数组编码为comparison_group。没有参数族合并或单位规范化/换算，现场编号不是分组主键。同号不同内部ID独立；缺单位或内部ID时追加完整来源键，使这些记录各自成组，不假定未知量纲可比。

绘图要求内部ID、趋势日期、非空单位均存在，且类别为exact_numeric或censored；否则保留原行并返回未绘图原因。解析使用Decimal，JSON保留字符串，绘图层转浮点；本轮移除期间汇总均值/范围。不同方法版本/量纲的等效合并、单位换算或参数族映射仍需OP-02先确认。

## 5. 限度与未启用的判断

独立期间汇总及精确子集均值/范围函数已删除；趋势显示原值与类别/绘图计数，总览只显示点位/年度样品数。本轮没有新增系统级数值平均、合格率或统计判断。

后续限度设计要求：警戒限、行动限、规格限分别定义，需关联水类型、取样点/系统、方法、参数、单位、生效区间、比较运算符、来源文件及规则版本。当前没有限度配置/判断模型，统一显示“未配置限度”，不输出“正常”或超限结论；未来若配置冲突，须另实现适用性校验。

删失值与限度比较需考虑区间：界值本身不能一律作为实测值判定。Cpk/Ppk、控制限、异常趋势/OOT、合格率及正式结论在业务口径确认前不启用。当前保留数值与文字结论并按参数分组，未实现自动矛盾提示或同图配对；后续若判断不一致，必须保留两者及来源。

## 6. 完整性规则

当前代码“取样点缺失”检查内部samplepointid；现场samplepoint_code为空是现场编号未映射，二者不同。结果表编号为空显示“未映射”，名称保持源字段。缺内部ID不归入点位趋势；旧质量通用映射提示已随专用接口删除（历史GAP-01）。系统/回路不从字符串推断。当前映射为current_master，明确提示不能证明历史有效期；按采样时点生效期关联是OP-01后续目标。

季度或年度“覆盖率”只有具备应取样计划和明确分母才能计算；已有结果数不能证明采样计划全部完成。分母缺失时显示实际样品数与数据缺口。

分析规则对照测试见 [docs/09](09-test-acceptance.md)。限度、方法可比性、时间语义和删失统计策略对应 OP-02。

## 7. 派生规则依赖与边界

精确值解析、类型区分、分别计数和原值展示已实现并有隔离测试；方法合并、单位换算、限度与定性判断依赖具体依据。缺单位时仍保留精确数值类别，但该记录不与单位已知的结果汇总在同一可比组；未知单位之间也不推断为同一量纲。

`trend_dt_source` 的合法标签来自上游 `collectiondt/eventdt/receiveddt/createdt`，其中 eventdt 对应宽表字段 sample_eventdt、createdt 对应 sample_createdt。全空时间时可能仍得到 createdt 标签，因此必须同时校验 trend_dt 非空，不能仅凭标签认定日期存在。


当前验收范围见 [docs/09](09-test-acceptance.md) 和 [STATUS](STATUS.md)。
